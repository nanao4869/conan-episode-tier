# データ更新ツール

エピソードのデータ（`data/episodes.js`）と画像（`img/`）を、元のサイトから作り直すためのスクリプトです。
新しい話が放送されたり、マンガの新しい事件が増えたときに実行します（YTVは毎週土曜に更新されます）。

## 使い方

```
cd tools
npm install          # 初回だけ
node build-data.mjs  # 更新（1分ほど）
```

- 取得済みのマンガの詳細ページ・画像は再取得しません。増えた分だけ取得します。
- マンガの詳細ページを全部取り直したいときは `node build-data.mjs --refresh` を使います。
- 終わったら `Tier表を開く.bat` で開いて、追加分が表示されるか確認してください。

## 何をしているか

| 段階 | 内容 | 取得元 |
|---|---|---|
| 1 | マンガの事件（タイトル・最初のFile・サムネイル・メインキャラ） | 少年サンデー「全事件レポート編纂室」 |
| 2 | アニメの全話（タイトル・放送日・サムネイル・詳細ページのURL） | 読売テレビ「事件ファイル」`case.json` |
| 3 | アニメオリジナルの判別、シーズン | Wikipedia「名探偵コナンのアニメエピソード一覧」 |
| 4 | マンガの事件とアニメ話の対応 | Wikipedia「名探偵コナンの漫画エピソード一覧」 |
| 5 | アニメオリジナルの登場キャラの推定 | 読売テレビのあらすじ（`character-aliases.mjs`） |
| 6 | 画像の取得・加工 | 上記サイト |
| 7 | `data/episodes.js` の書き出し | |

- **アニメオリジナル**は、Wikipediaの「原作」欄に「アニメオリジナル」とあり、File番号・巻の記載がない話です。
- **前編・後編など**は、連続する同名の話（`（前編）` `（後編）` `（事件編）`…）を1件にまとめます。
- **放送前の話**は含めません（放送日が今日より後のもの）。
- 画像は `img/`（元画像）と `img/t/`（一覧用の180px正方形の縮小版）に保存します。
  YTVのサムネイルのうち、黒い枠の中に小さな絵が入っているものは、枠を切り落として2倍に拡大します。

## アニメオリジナルの登場キャラについて

マンガには公式の「メインキャラ」一覧がありますが、アニメにはないので、あらすじ（とタイトル）に名前が出たキャラから推定しています。
名前の呼び方の対応表は `character-aliases.mjs` にあります。
マンガ側のアニメ化済み324事件で照合したところ、適合率は約94％、再現率は約70％でした（絞り込み用の目安で、完全な一覧ではありません）。
編纂室サイトで、名前ではなく通称のまま載っているもの（例：「領域外の妹」＝メアリー）は、`build-data.mjs` の `CHARACTER_RENAMES` で本来のキャラにまとめます。
新しいキャラがマンガ側に増えたときは、実行後に「別名が未登録」という警告が出るので、この表に追加してください。

## 舞台・事件のタイプ（タグ）について

集計画面の「舞台・事件」は、エピソードの題名・場所・あらすじにある言葉から自動で付けたタグです。
ルールは `tag-rules.mjs` にあり、言葉を足したり直したりして `node build-data.mjs` を実行すると、タグの件数（マンガ／アニメ）が表示されます。
「山」「島」のような短い言葉は、人名（山村、小島）にも当たるので、なるべく具体的な言葉にしてください。
マンガ側の「場所」と「事件の内容」は `tools/cache/manga-pages.json` に保存されます（画面用のデータには、タグの番号だけを入れます）。

## 集計画面のグループ分け

「グループ」タブの分け方（少年探偵団・警察・黒ずくめの組織など）は、`script.js` の `STATS_GROUPS` にあります。
新しいキャラが増えたときは、ここに追加してください。

## 実行後に確認すること

実行の最後に表示される警告（`!` で始まる行）を確認してください。

- **「Wikipediaにまだ載っていない話」**：放送されたばかりの話は、Wikipediaへの反映が遅れることがあります。
  その間はアニメオリジナルかどうか判別できないので、一覧に入れずに保留します。数日後にもう一度実行してください。
- **「Wikipediaの一覧が想定と違う」というエラー**：Wikipediaの表の作りが変わった可能性があります。`build-data.mjs` の `loadWikiAnime` / `loadWikiManga` を確認してください。

## 注意

- サイトの構成が変わると、取得部分が動かなくなることがあります。
- 画像はすべて小学館・読売テレビのものです。公開するときは、出典の表記（`index.html` のフッター）を残してください。
- `tools/node_modules/` と `tools/cache/` は再生成できるので、公開する必要はありません。
